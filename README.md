## 📡 О проекте

**RADAR** — локальное настольное приложение для Windows, предназначенное для быстрого поиска, умной фильтрации и мониторинга свежих качественных релизов с трекеров (uTorr / RuTor / RuTracker).

Больше не нужно вручную пролистывать сотни страниц и отсеивать раздачи сомнительного качества — RADAR делает это автоматически.

---

## ✨ Основные возможности

* **5 категорий в один клик:** 🎬 Фильмы, 📺 Сериалы, ⛩️ Аниме, 🎮 Игры, 💻 Программы.
* **Быстрые фильтры:**
  * По дате: последние 7 дней, 14 дней, месяц или за всё время.
  * По качеству: строго 1080p, 720p, 4K.
  * По размеру: отсечение тяжелых раздач (по умолчанию до 15 GB).
  * По рейтингу: фильтрация > 7.0 (Кинопоиск и IMDb).
  * По жанрам: выпадающий список всех актуальных жанров.
  * Живой поиск по названию, актёрам, режиссёрам.
* **Лёгкая витрина (ровно 15 карточек на страницу):**
  * Постер, название, год, бейджи рейтингов.
  * Размер релиза и живые счётчики сидов (`▲`) и пиров (`▼`).
  * Постраничная пагинация со стрелками.
* **Подробное модальное окно (все 16 полей релиза):**
  * Полное описание сюжета (синопсис), режиссёр, актёры, хронометраж.
  * **Аудиодорожки и субтитры:** наглядные бейджи с языками, студиями озвучки, кодеками и субтитрами.
  * **Блок сезонов для сериалов:** быстрые кнопки для перехода к 1, 2, 3 сезонам.
  * Прямая загрузка `.torrent` и `magnet`-ссылка.
* **Интерактивная консоль отладки:** сворачиваемый терминал внизу экрана со статусами работы в реальном времени.

## 🚀 Установка и запуск

1. **Клонирование репозитория:**
   ```bash
   git clone https://github.com/<username>/RADAR.git
   cd RADAR
   ```

2. **Автоматическая установка:**
   Просто запустите файл **`install.bat`**:
   * Он автоматически создаст изолированное виртуальное окружение `.venv`.
   * Обновит `pip` и установит все необходимые библиотеки из `requirements.txt`.

3. **Запуск приложения:**
   * Запустите **`run_radar.bat`** (или ярлык на Рабочем столе).
   * Приложение автоматически откроется в вашем браузере по адресу `http://127.0.0.1:8765`.

## 🛠️ Стек технологий

* **Backend:** Python 3.10+, SQLite (`radar.db`), `curl_cffi` (обход Cloudflare), `BeautifulSoup4`.
* **Frontend:** HTML5, CSS3 (Modern Glassmorphism Dark Theme), Vanilla JavaScript.
* **Архитектура:** Single-Page Application (SPA) с локальным REST API.
