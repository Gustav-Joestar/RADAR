## 📡 О проекте

**RADAR** — локальное настольное приложение для Windows, предназначенное для быстрого поиска, умной фильтрации, каталогизации и мониторинга свежих качественных релизов с трекеров (uTorr / RuTor / RuTracker).

RADAR избавляет от необходимости вручную пролистывать страницы трекера: он автоматически парсит релизы, находит вертикальные постеры высокого разрешения, раскладывает аудиодорожки и субтитры по полочкам и позволяет приложению работать **полностью автономно без постоянного доступа в интернет**.

---

## ✨ Основные возможности

* **5 категорий в один клик:** 🎬 Фильмы, 📺 Сериалы, ⛩️ Аниме, 🎮 Игры, 💻 Программы (со строгой изоляцией категорий — игры и софт не попадают в кино).
* **Полная офлайн-автономность (Offline Cache):**
  * Все обложки и постеры кэшируются локально на диск в `data/posters/`.
  * Локальный сервер отдаёт картинки по собственному маршруту `/posters/<id>.jpg` без обращений к внешним хостингам.
  * Фоновый загрузчик автоматически сохраняет постеры для всех отображаемых релизов.
* **Умный подбор вертикальных постеров:**
  * Поисковый движок постеров с фильтрацией `aspect-tall` (вертикальный кинопостер 2:3) и приоритетом кинобаз (Кинопоиск, Кинориум, Kinonews, Film.ru, KG-Portal).
  * Возможность ручного выбора и замены постера прямо в карточке релиза.
* **Универсальный парсер аудиодорожек и субтитров:**
  * Автоматическое распознавание любых форматов оформления раздач: многострочные переводы (`Перевод 1, 2...`, `Озвучка`, `Дубляж`), дорожки звука (`Аудио #01`, кодеки, битрейт, каналы) и субтитры (Forced, Full).
  * Карточки модального окна наглядно отображают отдельные бейджи для каждого перевода (🎙️), аудиодорожки (🔊) и субтитров (💬).
* **Списки «Буду смотреть» (Watchlist) и «Не буду смотреть» (Hidden):**
  * Пометка релизов в модальном окне или на витрине.
  * Фильмы из списка «Буду смотреть» защищены от удаления из кэша и всегда доступны локально.
  * Скрытые релизы убираются из повседневной ленты, но подсвечиваются бейджами 🚫 и 💚 при точном поиске по названию.
* **Быстрые фильтры и живой поиск:**
  * По дате: за 7 дней, 14 дней, месяц или за всё время.
  * По годам: выборка конкретных годов (от 2026 до 2000) и архивные диапазоны (до 2000, до 1990).
  * По качеству: 2160p (4K), 1080p, 720p.
  * По размеру: отсечение слишком тяжелых раздач.
  * По рейтингу: фильтрация > 7.0 (Кинопоиск / IMDb).
  * По 14 ключевым жанрам с регистронезависимым поиском (Unicode-совместимость в SQLite).
  * Живой поиск по названию, актёрам и режиссёрам.
* **Лёгкая витрина (ровно 15 карточек на страницу):**
  * Вертикальные постеры, бейджи качества, рейтинги, размер, сиды (`▲`) и пиры (`▼`).
  * Постраничная пагинация со стрелками.
* **Подробное модальное окно релиза:**
  * Полный синопсис, режиссёр, актёры, хронометраж, технические характеристики видео и звука.
  * Быстрый выбор сезонов для сериалов.
  * Прямая ссылка на `.torrent` файл и `magnet`-ссылка.
* **Интерактивная консоль отладки:** сворачиваемый терминал внизу интерфейса со статусами работы в реальном времени.

## 🚀 Установка и запуск

1. **Клонирование репозитория:**
   ```bash
   git clone https://github.com/<username>/RADAR.git
   cd RADAR
   ```

2. **Автоматическая установка:**
   Запустите файл **`install.bat`**:
   * Создаст изолированное виртуальное окружение `.venv`.
   * Обновит `pip` и установит зависимости из `requirements.txt`.

3. **Запуск приложения:**
   * Запустите **`run.bat`**.
   * Приложение в фоновом режиме поднимет локальный сервер и откроет интерфейс в браузере по адресу `http://127.0.0.1:8765`.

## 🔌 API эндпоинты локального сервера

| Метод | Эндпоинт | Описание |
| :--- | :--- | :--- |
| `GET` | `/api/releases` | Получение списка релизов с поддержкой фильтров, пагинации и поиска |
| `GET` | `/api/release_details?id=<id>` | Полные детали релиза (звук, субтитры, синопсис) |
| `GET` | `/api/genres?category=<cat>` | Список доступных жанров для категории |
| `GET` | `/api/watchlist` | Получение списков «Буду смотреть» и «Не буду смотреть» |
| `POST`| `/api/watchlist` | Добавление / удаление релиза из списков |
| `GET` | `/api/poster_search?q=<title>` | Поиск альтернативных вертикальных постеров в сети |
| `POST`| `/api/update_poster` | Сохранение выбранного постера в БД и локальный кэш |
| `GET` | `/posters/<id>.jpg` | Отдача закэшированного постера с локального диска |
| `GET` | `/api/logs` | Поток логов для встроенной консоли отладки |

## 🛠️ Стек технологий

* **Backend:** Python 3.10+, SQLite (`radar.db`), `curl_cffi` (имперсонация браузера и обход Cloudflare), `BeautifulSoup4`.
* **Frontend:** HTML5, CSS3 (Modern Glassmorphism Dark Theme), Vanilla JavaScript.
* **Архитектура:** Single-Page Application (SPA) с локальным REST API и дисковым кэшем медиа-ассетов.
